# 고객 전달 전 체크리스트

## 소스코드 정리
- [ ] 작업용 임시 파일·백업본(`*_old.html`, `*_test.html`, `사본` 등) 제거
- [ ] 파일명을 순서·용도가 드러나게 통일 (예: `01_header.html`, `02_hero.html` …)
- [ ] 각 파일 상단에 "어느 섹션에 들어가는 코드인지" 주석 추가
- [ ] 콘솔 로그, 주석 처리된 실험 코드 제거
- [ ] 이미지 파일은 `images/` 폴더로 분리, 파일명 영문화

- [ ] 모바일(360px) / 태블릿 / 데스크톱 화면 깨짐 확인
- [ ] 개발용 테스트 문구·더미 텍스트 잔존 여부 확인
