### 2. 페이지 구성

헤더 → 풀화면 메인 슬라이드 → 바로가기 바 → **취급제품 14종**
→ 회사소개 · 사업분야 → **시공사례 26장** → 스마트스토어·전화 문의 → 푸터

- 제품 카드를 클릭하면 해당 제품 사진이 갤러리 창으로 열립니다.
- 시공사례는 [더보기] 버튼으로 6장씩 추가로 보이도록 되어 있습니다.
- 우측 하단에는 스마트스토어 바로가기 버튼이 항상 떠 있습니다.
- PC · 태블릿 · 휴대폰 화면에 모두 맞춰 제작되었습니다.
