## 1. 파일 구성

| 파일 | 설명 |
|---|---|
| `01_seoulblock_full_page.html` | **완성본 전체 페이지.** 더블클릭하면 브라우저에서 바로 열립니다. |
| `02_seoulblock_imweb_widget.html` | **아임웹에 붙여넣는 파일.** 위 파일에서 `<html>`·`<head>` 부분만 뺀 것으로, **내용은 완전히 동일**합니다. |

> 그래서 파일 2개만으로 홈페이지 전체가 그대로 동작합니다.

## 2. 아임웹에 적용하는 방법

1. 아임웹 관리자 → **사이트 편집** 진입
2. 원하는 위치에 **위젯 추가 → HTML** 선택
3. `02_seoulblock_imweb_widget.html` 파일을 메모장(또는 VS Code)으로 열고
   **전체 선택(Ctrl+A) → 복사(Ctrl+C)**
4. 아임웹 HTML 위젯 입력창에 **붙여넣기(Ctrl+V)** → 저장
5. 화면 상단 여백이 생기면, 해당 섹션의 **상하 여백(padding)을 0** 으로 맞춰주세요.

> **이용약관 / 개인정보처리방침** 링크는 아임웹 기본 모달과 연동되도록
> `data-terms-mode` 속성을 사용했습니다. 아임웹 관리자에서 약관 내용만 등록해 두시면
> 별도 작업 없이 팝업으로 열립니다.

## 4. 직접 수정하실 때 (자주 쓰는 것만)

모든 수정은 파일 **아래쪽 `<script>` 영역**에서 이뤄집니다.
메모장으로 열어 `Ctrl+F` 로 아래 단어를 찾으시면 바로 나옵니다.

### 전화번호 바꾸기
`010-3388-2121` 로 검색 → 나오는 곳을 모두 새 번호로 교체합니다.
이때 `tel:01033882121` 처럼 **하이픈 없는 형태**도 같이 바뀌어야 클릭 통화가 동작합니다.

### 제품 추가 / 사진 교체 — `var PRODUCTS`
```js
{ name:'투수 블럭', tag:'투수\n블럭', desc:'빗물이 스며드는<br> 보도 · 광장용 포장재',
  imgs:[
    {src:'https://cdn.imweb.me/upload/.../a67c2f11c60bb.jpg', cap:'투수 블럭 (200×100)'}
  ]},
```
- `name` : 카드 제목 · 상세창 제목
- `tag` : 동그라미 안 글자 (`\n` 은 줄바꿈)
- `desc` : 카드 설명 (`<br>` 로 줄바꿈)
- `imgs` : 상세창에 뜨는 사진 목록. `src` 는 아임웹에 올린 사진 주소, `cap` 은 사진 설명
- 제품을 **추가**하려면 `{ ... }` 한 덩어리를 통째로 복사해 붙이고 내용만 바꾸면 됩니다.
  (앞 항목 끝에 쉼표 `,` 가 있는지 꼭 확인해 주세요.)

### 시공사례 사진 추가 — `var WORKS`
```js
{src:'https://cdn.imweb.me/upload/.../6c52053824ad4.jpg', cap:'보도 포장 · 공원 산책로 시공'},
```
줄 하나가 사진 한 장입니다. 줄을 복사해 붙여넣고 `src` 와 `cap` 만 바꾸면 됩니다.

### 사업분야 4개 카드 — `var BIZ`
`tit`(제목) · `en`(부제) · `src`(사진) 를 바꾸면 됩니다.
`show:[186,-22.5]` 는 사진 크기와 위치 값이니, 사진을 바꾸셨을 때 위치가 어색하면
앞 숫자(크기)와 뒤 숫자(위쪽 이동)를 조금씩 조정해 보세요.

### 새 사진을 올리는 방법
1. 아임웹 관리자에서 사진을 업로드합니다.
2. 업로드된 사진을 **마우스 오른쪽 클릭 → 이미지 주소 복사**
3. 복사한 주소를 위 `src:'...'` 자리에 붙여넣습니다.

## 5. 참고 사항

- **수정 전에는 반드시 원본 파일을 복사해서 따로 보관**해 주세요.
- 사용된 글꼴(Wanted Sans, Pretendard, Noto Sans KR)은 모두 **상업적 이용이 가능한 무료 글꼴**입니다.
- 외부 라이브러리(제이쿼리 등) 없이 순수 HTML/CSS/JavaScript로만 제작되어,
  아임웹 업데이트나 다른 위젯과 충돌할 가능성이 낮습니다.
- 모든 클래스 이름에 `sbb-` 접두사를 붙여 **다른 섹션의 디자인을 건드리지 않습니다.**
- PC · 태블릿 · 모바일 화면에 모두 대응되어 있습니다.
- 사용자가 [동작 줄이기] 설정을 켠 기기에서는 슬라이드 애니메이션이 자동으로 멈춥니다.
