# 계약서 서명 툴 — 카카오톡에서 바로 서명하기

## 1. 지금까지 왜 카톡에서 서명이 안 됐나요?

계약서를 **HTML 파일로 첨부해서** 보냈기 때문입니다.

카카오톡 대화방에서 파일을 탭하면 카톡은 그 파일을 **웹페이지로 실행하지 않고**
자체 문서 뷰어로 "글자만" 보여줍니다. 서명판은 자바스크립트로 그리는 그림판이라
자바스크립트가 실행되지 않으면 아예 나타나지 않습니다.
(그래서 지금까지 "공유 → 다른 브라우저로 열기"를 안내할 수밖에 없었습니다.)

이건 파일 내용을 고쳐서 해결할 수 있는 문제가 아닙니다. 카톡이 첨부파일을
어떻게 열지 결정하는 문제라서요.

## 2. 해결 방법 — 파일 대신 **링크**를 보냅니다

카카오톡은 **링크(주소)** 를 누르면 인앱 브라우저로 실제 웹페이지를 띄웁니다.
이때는 자바스크립트가 정상 실행되므로 **카톡 안에서 손가락으로 바로 서명**이 됩니다.

```
[기존]  계약서.html 파일 전송  →  카톡 문서뷰어  →  글자만 보임, 서명 불가
[변경]  서명 링크 전송         →  카톡 인앱 브라우저  →  계약서 화면, 서명 가능 ✅
```

계약 내용은 링크의 `#` 뒤에 담겨 전달됩니다. `#` 뒤 값은 **서버로 전송되지 않기 때문에**
계약 내용이 외부 서버에 저장되지 않습니다.

## 3. 설치 (한 번만 하면 됩니다)

### 3-1. 계약서를 웹에 올리기

링크로 보내려면 `contract/index.html` 이 인터넷 주소를 가지고 있어야 합니다.
둘 중 편한 쪽을 고르세요.

**A. GitHub Pages (무료, 추천)**

1. GitHub 저장소 → **Settings → Pages**
2. *Source* 를 **Deploy from a branch** 로 두고, 브랜치를 이 파일이 있는 브랜치로 선택 → **Save**
3. 1~2분 뒤 아래 주소로 열립니다.
   ```
   https://hyojung5732-lab.github.io/-/contract/
   ```

**B. 아임웹 등 기존 홈페이지에 업로드**

`contract/index.html` 을 서버에 올리고 그 주소로 엽니다. 외부 라이브러리를
전혀 쓰지 않는 파일 하나짜리라 어디에 올려도 그대로 동작합니다.

### 3-2. 서명 완료본을 자동으로 받기 (선택, 5분)

이 설정을 하면 **고객은 파일을 저장하거나 회신할 필요가 전혀 없습니다.**
[서명 완료] 버튼 한 번이면 제작자 이메일로 서명본이 자동 도착합니다.

1. <https://script.google.com> → **새 프로젝트**
2. `apps-script.gs` 내용을 통째로 붙여넣고, 맨 위 `OWNER_EMAIL` 을 내 이메일로 수정
3. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 꼭 이걸로 해야 고객 폰에서 전송됩니다
4. 배포하면 나오는 주소(`https://script.google.com/macros/s/.../exec`)를 복사
5. `contract/index.html` 을 열어 위쪽 `CONFIG` 의 `SUBMIT_URL` 에 붙여넣고 저장

```js
const CONFIG={
  SUBMIT_URL:"https://script.google.com/macros/s/AKfycb....../exec",
  OWNER_NAME:"여백웹"
};
```

> 이 설정을 건너뛰어도 됩니다. 그 경우 고객은 카톡 안에서 서명은 그대로 하고,
> 마지막에 완료본 파일을 저장해 회신하는 기존 방식으로 동작합니다.

## 4. 사용 순서

**제작자**
1. 웹에 올린 주소로 계약서 툴을 엽니다.
2. 계약 정보를 입력합니다. (을 도장은 자동으로 찍혀 있습니다)
3. **[🔗 고객 서명 링크 만들기]** 클릭 → 링크가 만들어지고 공유창이 뜹니다.
4. **[📤 카카오톡으로 보내기]** 또는 **[📋 링크 복사]** 후 카톡 대화창에 붙여넣기.

**고객**
1. 카톡에서 링크를 탭 → 계약서가 바로 열립니다.
2. 내용 확인 후 "갑(발주자)" 칸에 손가락으로 서명.
3. **[✅ 서명 완료]** 탭 → 끝. (3-2 설정을 했다면 제작자에게 자동 전송)

## 5. 자주 묻는 것

**Q. 고객이 링크를 잃어버렸어요**
A. 같은 링크를 다시 보내면 됩니다. 링크에 계약 내용이 그대로 들어 있습니다.

**Q. 링크가 너무 길어 보여요**
A. 계약 내용이 링크에 통째로 들어 있어서 그렇습니다. 카톡은 긴 링크도 정상적으로
   보냅니다. 짧게 보이고 싶으면 카톡에 붙여넣기 전에 단축 URL 서비스를 쓰면 됩니다.

**Q. 파일로 보내던 기존 방식은 없어졌나요?**
A. 그대로 있습니다. **[✉️ 고객 서명용 파일 만들기]** 버튼이 예전과 똑같이 동작합니다.
   인터넷에 올리기 전이거나, 링크를 쓰기 어려운 상황에 쓰세요.

**Q. 법적 효력이 더 필요한 계약이라면?**
A. 이 툴은 서명 이미지를 계약서에 넣어 보관하는 방식입니다. 본인 확인(휴대폰 인증)과
   타임스탬프까지 필요한 큰 계약이라면 모두싸인·이폼사인 같은 전자계약 서비스를
   쓰는 편이 안전합니다.
