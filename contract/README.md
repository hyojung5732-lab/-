# 계약서 서명 툴 — 카카오톡에서 바로 서명하기

## 1. 왜 지금까지 카톡에서 서명이 안 됐나요?

계약서를 **HTML 파일로 첨부해서** 보냈기 때문입니다.

카톡 대화방에서 파일을 탭하면 카톡은 그 파일을 **웹페이지로 실행하지 않고**
자체 문서뷰어로 "글자만" 보여줍니다. 서명판은 자바스크립트로 그리는 그림판이라,
자바스크립트가 실행되지 않으면 아예 나타나지 않습니다.

파일 내용을 고쳐서 해결되는 문제가 아닙니다. 카톡이 첨부파일을 어떻게 열지
결정하는 문제라서요.

## 2. 해결 — 파일 대신 **링크**를 주고받습니다

카톡은 **링크(주소)** 를 누르면 인앱 브라우저로 진짜 웹페이지를 띄웁니다.
이때는 자바스크립트가 정상 실행돼서 **카톡 안에서 손가락으로 바로 서명**이 됩니다.

```
[기존]  계약서.html 파일 전송  →  카톡 문서뷰어  →  글자만, 서명 불가
[변경]  서명 링크 전송        →  카톡 인앱 브라우저  →  서명 가능 ✅
```

**주고받는 방식은 그대로입니다.** 서버도, 이메일도, 가입도 없습니다.
고객이 서명하면 **고객이 카톡으로 사장님께 직접 회신**합니다. 파일 대신 링크로요.

```
제작자 ──[서명 요청 링크]──▶ 고객      (카톡)
제작자 ◀──[서명 완료 링크]── 고객      (카톡, 서명까지 링크 안에 들어 있음)
```

- 서명 요청 링크: 약 600자
- 서명 완료 링크: 약 900자 (서명 그림을 **획 좌표**로 담아서 짧습니다)

### 계약 내용을 링크 어디에 담는가 (중요)

처음에는 링크의 `#` 뒤에 담았습니다. `#` 뒤는 브라우저 밖으로 나가지 않아
서버에 아무것도 남지 않는 장점이 있었는데, **카카오톡이 링크를 인식할 때
`#` 뒷부분을 잘라내서** 고객 화면에 빈 계약서가 뜨는 문제가 있었습니다.

그래서 지금은 물음표 뒤(`?c=...`)에 담습니다. `?` 뒤는 주소의 정식 일부라
메신저가 잘라내지 않습니다. 대신 **주소를 여는 순간 그 내용이 웹서버(GitHub)
요청 주소에 포함**됩니다. 서버 접속 기록에 남을 수 있다는 뜻입니다.
계약서를 다루는 만큼 알고 계셔야 할 부분이라 적어둡니다.

- 이 기록은 공개되지 않고, 사장님이나 고객이 볼 수 있는 곳에 노출되지 않습니다.
- 그래도 신경 쓰이면 아임웹 등 **직접 관리하는 서버**에 올려 쓰시면 됩니다.
  그 경우 기록도 사장님 서버에만 남습니다.
- 이전에 `#` 방식으로 만들어 보낸 링크도 그대로 열립니다.

## 3. 딱 한 번 해야 하는 설정 — 웹에 올리기

링크를 쓰려면 `contract/index.html` 이 인터넷 주소를 가져야 합니다. 둘 중 하나만 하세요.

2. *Source* = **Deploy from a branch**,

3. 1~2분 뒤 아래 주소가 열립니다. 이 주소를 즐겨찾기 해두세요.
   ```
   https://hyojung5732-lab.github.io/-/contract/
   ```

### B. 아임웹 등 기존 홈페이지에 업로드

`contract/index.html` 을 서버에 올리고 그 주소로 엽니다.
외부 라이브러리를 전혀 쓰지 않는 파일 하나짜리라 어디에 올려도 그대로 동작합니다.

## 4. 바탕화면에 바로가기 만들기 (매번 주소 치기 번거로울 때)

**가장 쉬운 방법 — 앱으로 설치 (Chrome / Edge)**
1. 위 주소로 계약서 툴을 엽니다.
2. 주소창 오른쪽 끝의 **설치 아이콘(⊕ 또는 모니터 모양)** 클릭.
   안 보이면 브라우저 우측 상단 **⋮ → 캐스트·저장 및 공유 → 페이지를 앱으로 설치**.
3. 바탕화면과 시작 메뉴에 **여백웹 계약서** 아이콘이 생깁니다.
   주소창 없는 별도 창으로 열려서 프로그램처럼 쓸 수 있습니다.

**더 간단한 방법 — 주소창 아이콘 끌어놓기**
주소창 왼쪽의 자물쇠(또는 ⓘ) 아이콘을 **바탕화면으로 드래그**하면 바로가기가 생깁니다.

**폰 홈 화면에 추가**
- 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**
- 안드로이드(크롬): ⋮ → **홈 화면에 추가**

## 5. 사용 순서

**제작자**
1. 위 주소로 계약서 툴을 엽니다.
2. 계약 정보를 입력합니다. (을 도장은 자동으로 찍혀 있습니다)
3. **[🔗 고객 서명 링크 만들기]** → 공유창이 뜨면 고객 대화방 선택,
   또는 **[📋 링크 복사]** 후 카톡에 붙여넣기.

**고객** (카톡에서)
1. 링크를 탭 → 계약서가 바로 열립니다.
2. 내용 확인 후 "갑(발주자)" 칸에 손가락으로 서명.
3. **[✅ 서명 완료 · 제작자에게 보내기]** → 공유창에서 제작자 대화방 선택. 끝.

**제작자** (회신 받은 뒤)
1. 고객이 보낸 링크를 탭 → 갑·을 서명이 모두 들어간 완료본이 열립니다.
2. **[🖨️ PDF로 저장]** 또는 **[💾 HTML 파일로 저장]** 으로 보관.
   (카톡 안에서 저장이 안 되면 안내 배너의 **[외부 브라우저로 열기]** 를 누르세요)

## 6. 자주 묻는 것

**Q. 고객이 링크를 잃어버렸어요**
A. 같은 링크를 다시 보내면 됩니다. 링크에 계약 내용이 그대로 들어 있습니다.

**Q. 고객 화면에 계약 내용이 하나도 안 나와요**
A. 화면에 뜨는 안내를 보세요.
   - **빨간 배너**(링크의 뒷부분이 전달되지 않았습니다): 메신저가 링크를 중간에
     잘라먹은 경우입니다. 대화방에서 **링크를 길게 눌러 [복사]** 한 뒤, 배너 안의 칸에
     붙여넣고 [열기] 를 누르면 정상적으로 열립니다.
   - **노란 배너**(계약 내용이 비어 있습니다): 제작자가 정보를 입력하기 **전에** 링크를
     만든 경우입니다. 정보를 채운 뒤 링크를 다시 만들어 보내면 됩니다.
     링크는 만든 순간의 내용을 담는 스냅샷이라, 만든 뒤에 폼을 고쳐도 이미 보낸 링크는
     바뀌지 않습니다.

**Q. 링크가 길어 보여요**
A. 계약 내용과 서명이 링크에 통째로 들어 있어서 그렇습니다. 카톡은 이 정도 길이는
   문제없이 보냅니다. 짧게 보이고 싶으면 붙여넣기 전에 단축 URL 서비스를 쓰세요.

**Q. 파일로 보내던 기존 방식은 없어졌나요?**
A. 그대로 있습니다. **[✉️ 고객 서명용 파일 만들기]** 버튼이 예전과 똑같이 동작합니다.
   PC 로 주고받거나, 웹에 올리기 전이라면 이걸 쓰세요.

**Q. 서명이 그림이 아니라 좌표로 저장된다는 게 무슨 뜻인가요?**
A. 손가락이 지나간 점들의 위치만 저장하고, 열 때 그 위치대로 다시 그립니다.
   그림파일(6KB↑)보다 훨씬 작아서 링크에 담을 수 있고, 화면 크기가 달라져도
   서명이 뭉개지지 않습니다. 저장하는 HTML·PDF 에는 똑같이 그림으로 들어갑니다.

**Q. 법적 효력이 더 필요한 계약이라면?**
A. 이 툴은 서명 이미지를 계약서에 넣어 보관하는 방식입니다. 본인 확인(휴대폰 인증)과
   타임스탬프까지 필요한 큰 계약이라면 모두싸인·이폼사인 같은 전자계약 서비스가
   안전합니다.
